\section{Conclusion}

\begin{frame}{Summary of this Work}{}

    \textbf{Conclusion}

    \begin{itemize}
        \item Contraction condition is projected onto tracking error, resulting in vector-space optimization problem.
        \item Input saturation is directly incorporated into the optimization problem.
    \end{itemize}

    \textbf{Future work}

    \begin{itemize}
        \item Additional constraints, such as state constraints and CBF-motivated constraints, and input constraints will be considered.
        \item Since projected contraction condition is necessary but not sufficient, we will investigate the conditions under which the projected contraction condition is sufficient.
    \end{itemize}
    
\end{frame}
